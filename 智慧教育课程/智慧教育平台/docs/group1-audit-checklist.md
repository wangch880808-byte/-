# 第一组权限与审计联合验收清单

本文件适用于对第 2～5 组实际接口的独立复核。它是待执行清单，不是已通过记录。不建立受限教务管理员。

## 第一组本地回归

- 三角色正确入口登录、错角色入口拒绝、退出、令牌失效、刷新与浏览器返回。
- 用户新增/编辑/启停/改密/授权；角色增改/停用/菜单授权/数据范围；菜单和部门增改删。
- 双会话验证：账号停用和撤权后旧令牌请求被拒；角色停用、菜单权限缩小和数据范围缩小后受影响普通会话重新登录。
- 五类管理页面分别检查正常、空数据、无权限、失败。403 后正文和弹窗不可继续显示旧内容。
- 教师、学生改 URL 或直接调用管理接口均应拒绝。
- 操作审计可按操作者、时间查到启停、授权、改密及关键变更，失败操作也保留结果。

## 业务组对象级权限矩阵

各组应提供有权限本人/本班、他人、外班、已退班、已撤权、对象已归档的测试数据与接口。第一组复核身份来源、403 语义及撤权效果；对象归属与成员规则由业务组维护。

| 提供方 | 必查对象 | 必查案例 |
|---|---|---|
| 2A | 上下文、课程、教学班、成员 | 同一课程/班级绑定、他人班级、退班、调班、角色与对象权限分离 |
| 3A | 资源、预习、答案 | 发布范围、撤回后旧下载、教师私有资料、未公布答案 |
| 4A | 课堂、活动、实时订阅 | 外班加入、重复提交、重连重新授权、投影公开载荷 |
| 5A | 作业、提交、批改、成绩 | 本人提交、他人记录、成绩发布前不可见、更正留痕 |

每条记录：接口、操作者角色与脱敏测试账号、对象 ID、前置状态、预期/实际 HTTP 与业务码、响应是否含私有内容、执行时间、执行人、独立审核人。未执行项标为待联调，不能填“通过”。

## 审计规则

已有若依 @Log 覆盖系统用户、角色、菜单和部门的主要变更。业务组对授课授权、成员变更、发布/撤回、答案公布、批改、成绩发布/更正等操作增加审计，记录操作者、对象标识、动作、结果与时间。成绩更正还应记录原因与版本。

不得把令牌、密码、验证码、私有答案、学生整份提交内容或真实敏感数据写入审计。日志页面权限由 monitor:operlog 控制；后端拒绝教师/学生越权访问。跨组验收由接口提供方和第一组共同确认，作者不能自审自己的 PR。
