1. options/check 尚无真实 Java 实现。2A 需确认同一班多课程绑定、无绑定课程、当前学期、受限管理员行为、ID/时间格式，并让服务端实际校验课程与班级的同一绑定。

## 复现方式

工程根执行：

```powershell
node --test tests/frontend-regressions.test.cjs tests/context-permissions.test.cjs tests/shell-integration.test.cjs
```

前端资源打入 ruoyi-admin.jar；更新后停止本项目 Java 进程，在 backend 使用 JDK 17 执行 `mvn.cmd -o -B -pl ruoyi-admin -am package`，再按现有本地配置启动。当前调试将日志写入 backend/logs，避免上游绝对日志路径；日志、配置和构建产物不提交。

此交付不构成全部 M0、1-03 或 G0 的整体验收。真实教学上下文、受限管理员和其他组页面仍有外部依赖；不得将前端代码和模拟测试记为对应后端已完成。
