## 五、处理建议

1. **前端标注**：建议在 admin.html 目录里把上述「缺口/若依/部分」项打上 `M1 / M2 / M+ / 若依` 角标，避免评审时误当 M0 已实现。
2. **M0 优先补齐**（可落地、且影响教学闭环）：留言/互动（edu_course_announcement 之外的学生留言）、操作审计日志（edu_* 表的改动留痕）。
3. **M1 及以上**：能力评测、证书、实训、AI 控制台、校园资讯按后续排期独立建表，不提前塞进 M0。
4. **若依项**：不自行建表，待选定若依基础工程后对接真实 ID 与数据权限。
5. **部分覆盖项**：明确"服务端聚合"与"专表"的取舍——教学总览/看板可先走聚合，无需为每块卡片单独建表。
