# 数据库脚本

以根目录 [运行说明.md](../运行说明.md) 的操作步骤为准。本轮没有执行这些 SQL，也没有读取或修改现有数据库。

| 文件 | 用途与前提 |
|---|---|
| install-fresh.sql | 仅新建空库。含上游重建表、44 张教学业务表、虚构演示数据、登录账号、身份视图和菜单权限。不能对已有库执行。 |
| upgrade-course-content.sql | 在现有业务库执行一次，增加章节正文、附件和课程逻辑删除支持，可重复执行。 |
| upgrade-group12.sql | 已有同版本 sys_* / edu_* 基础表的库；补当前学期、身份视图与权限；不写演示数据或账号密码。先备份。 |
| group12-system-directory.sql | 第一组提供的四个只读身份目录视图，第二组不直接查询系统私有表。 |
| group12-menu-permissions.sql | 可重复执行的第二组页面／操作权限与三角色授权。 |
| mysql-v3-m0-core-schema.sql | 教学核心表的单项建表脚本；已被新安装总脚本包含。 |
| mysql-v3-m0-teaching-schema.sql | 教学扩展表的单项建表脚本；保留其他组的数据约束，表存在不等于业务已实现。 |
| demo-v3-m0-seed.sql | 虚构教学数据，须空教学表；已被总脚本包含，不能重复叠加导入。 |
| demo-v3-m0-ruoyi-login-seed.sql | 仅演示新库的账号／角色绑定，所有文档列出的演示密码为 Edu@123456。 |
| upstream/ruoyi | 原始若依系统表与定时任务 SQL、来源记录。 |

导入总脚本前必须选中目标库。本版不强制 USE 某个本机库名。全新演示安装使用 +08:00 时间和当前时间生成演示成员区间；JDBC 示例同样指定 Asia/Shanghai 并固定连接会话时区。后续跨组时区契约以实际业务接口约定为准。
