# 2026-11-09

## 本地启动排障（http://127.0.0.1:8081/login.html 打不开）
- 根因链：`backend/.env` 缺失 + `ruoyi-admin.jar` 未生成，`run-local.ps1` 前置校验直接抛错；真正启动时又因宿主环境注入 `SERVER__PORT=56723`（WorkBuddy 服务代理端口且已被占用），被 Spring Boot 当作 `server.port` 覆盖 `application.yml` 的 8081，日志报 `Port 56723 was already in use`，所以 8081 始终无监听。
- 处理：在线执行 `mvn -B -f backend/pom.xml -pl ruoyi-admin -am package -DskipTests` 成功（此前离线 `-o` 构建因本地 pdfbox 仓库 id 不匹配失败，别加 `-o`）；新建 `backend/.env`（值取自 `application-druid.yml`，该文件被 .gitignore 忽略）；`run-local.ps1` 增加 `--server.port=8081` 命令行参数锁定端口；`backend/README.md` 修正旧机器绝对路径并新增「启动失败排查」小节。
- 验证：MySQL 3306、Redis 6379 均在跑；`env -u SERVER__PORT -u SERVER__HOST java -jar ... --server.port=8081` 启动成功，`/login.html`、`/teacher.html`、`/student.html`、`/group3.js`、`/group3.css`、`/captchaImage` 全部 200。
- 注意：终端存在 `HTTP_PROXY=http://127.0.0.1:51430`，直接 `curl 127.0.0.1` 会返回 502，验证必须 `curl --noproxy '*'`；浏览器若报 502 需把 127.0.0.1/localhost 加入不使用代理。
- 前端源码仍在 `frontend/`，改动后需重新 `mvn package` 才会拷入 `target/classes/static`。
