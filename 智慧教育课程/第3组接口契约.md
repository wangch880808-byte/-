# 第3组接口契约说明

> 第3组：课程资源、题库与课前（3-01 ~ 3-04） · 整理日期：2026-10-29
> 本文与《第3组跨组对接说明.docx》内容一致，整理为 Markdown 便于转发各组。

## 一、第3组负责范围

- **3-01（后端）**：课程资源上传、版本记录、处理状态、受控预览、按教学班发布/撤回；PPTX/PDF 转换与页码验证。
- **3-02（后端）**：题库题目及答案/解析版本、备课方案、预习资源与测验的发布契约（预习提交由第5组统一作业引擎承接）。
- **3-03（前端）**：教师端“课程建设”“课前准备”页面：`teacher-course-build.html`、`teacher-question-bank.html`、`teacher-lesson-plan.html`、`teacher-preview-publish.html`。
- **3-04（前端）**：学生端“课程资料”“课前学习”页面：`student-course-study.html`。

## 二、第3组向其他组提供

### 2.1 提供给第1组（基础平台）

权限点清单（已注册于 `sql/mysql-v3-m0-edu-permissions.sql`，菜单 7000-7033）：

| 权限点 | 说明 |
|--------|------|
| `education:resource:query` | 资源查询（学生端共用） |
| `education:resource:upload` | 创建资源/追加版本 |
| `education:resource:publish` | 发布到教学班 |
| `education:resource:revoke` | 撤回发布 |
| `education:question:list` / `query` / `edit` | 题库列表 / 详情（含解析）/ 创建与状态流转 |
| `education:assignment:query` / `publish` / `close` | 预习查询 / 发布 / 提前关闭 |
| `education:plan:query` / `edit` / `ready` / `archive` | 备课方案查询 / 编辑 / READY / 归档 |

前端页面文件（5 个）：`teacher-course-build.html`、`teacher-question-bank.html`、`teacher-lesson-plan.html`、`teacher-preview-publish.html`、`student-course-study.html`。

### 2.2 提供给第2组（课程与教学班）

资源、题目、备课方案均按 `courseSpaceId`、`bindingId` 挂载；第3组对课程空间、教学班数据**只读引用，不做写入**。

### 2.3 提供给第4组（课堂教学）——数据表只读契约

| 数据 | 说明 |
|------|------|
| `edu_lesson_plan`（READY 状态） | 备课方案，READY 后供课堂引用 |
| `edu_lesson` | 课次，课堂 session 的前置容器 |
| `edu_question_version` | 题目版本，供课堂活动模板引用 |
| `edu_resource_page` | PPTX/PDF 转换后的页码图片，可供课堂投影复用 |

### 2.4 提供给第4组 / 第5组——题库接口（已实现，可直接联调）

| 接口 | 权限 | 说明 |
|------|------|------|
| `GET /education/questions/{questionId}` | `education:question:query` | 题目详情：题干、选项 `options_json`、答案 `answer_json`、解析 `explanation`、满分 `max_score`、当前版本号 |
| `GET /education/course-spaces/{courseSpaceId}/questions` | `education:question:list` | 分页列表，支持状态筛选 |
| `POST /education/questions/{questionId}/activate` | `education:question:edit` | 启用 |
| `POST /education/questions/{questionId}/archive` | `education:question:edit` | 归档 |

用法约定：第4组课堂随堂题直接引用 `question_version_id` 渲染与判分；第5组作业题目项（`edu_assignment_item`）已按此契约引用。

### 2.5 提供给第5组（统一作业引擎）——预习发布契约

| 接口 | 权限 | 说明 |
|------|------|------|
| `POST /education/bindings/{bindingId}/assignments/preview` | `education:assignment:publish` | 创建 PREVIEW 类型预习草稿 |
| `POST /education/assignments/{id}/publish` | `education:assignment:publish` | 发布 |
| `POST /education/assignments/{id}/close` | `education:assignment:close` | 提前关闭 |
| `GET /education/bindings/{bindingId}/assignments/preview` | `education:assignment:query` | 预习列表 |
| `GET /education/assignments/{id}` | `education:assignment:query` | 预习详情 |

题目项引用 `question_id` + `question_version_id`。

### 2.6 提供给第6组（通知）

预习发布/关闭事件的来源数据：作业 id、目标教学班、开放与截止时间（`edu_assignment`、`edu_assignment_target`）。

## 三、第3组需要其他组提供

### 3.1 需要第1组（基础平台）

- 登录与令牌体系：`login.html`、sessionStorage 键 `zhijiao.login.token`、`Authorization: Bearer` 头；
- `@PreAuthorize` 权限框架与 `teacher` / `student` 角色；
- **外壳页面导航接入**：`teacher.html` / `student.html` 左侧目录目前为硬编码 `MENU` 数组（`href` 仅为页内参数），第3组 5 个页面无入口，需加入可跳转链接。

### 3.2 需要第2组（课程与教学班）

- **教学班与课程绑定列表的查询接口**：当前无 Controller 暴露，前端 `bindingId` 只能手工输入（默认值 `910000000001`）；
- `edu_class_teacher` 授课关系数据（`CourseAccessGuard` 越权校验依赖）；
- `edu_class_student` 学生名单（发布目标范围）。

### 3.3 需要第4组（课堂教学）

- 课次与课堂 session 的衔接约定（`edu_class_session.lesson_id` 引用 `edu_lesson`）；
- 课堂引用备课方案、题目版本时走只读契约，不直接写第3组的表。

### 3.4 需要第5组（统一作业引擎）

- 统一作业引擎接口：PREVIEW 创建 / 发布 / 关闭（见 2.5）；
- 学生端作业列表与详情查询（`/education/student/bindings/{bindingId}/assignments`、`/education/student/assignments/{id}`）；
- **学生预习提交接口**（当前学生端页面只能查看，提交入口在第5组）；
- 作业目标快照 `edu_assignment_target`。

### 3.5 需要第6组（通知）

- 预习发布后向目标学生发送通知（`EduUserNotice`）；
- 截止提醒（可选）。

## 四、当前已确认的对接缺口

1. **外壳导航缺口**：`teacher.html` / `student.html` 目录硬编码，`/getRouters` 返回值未被渲染，第3组页面无入口（待第1组或 3B 接线）。
2. **教学班选择缺口**：无教学班/绑定查询接口，`bindingId` 手写默认值，换库即失效（待第2组）。
3. **学生提交缺口**：学生端只有查询接口，无法提交预习（待第5组）。
