## 5. 四类验收用例（页面级，联调时逐条留证）

### 5.1 正常

| # | 步骤 | 期望 |
|---|---|---|
| N1 | `eduadmin` 建学期「2026-2027-1」→ 设为当前 | 列表出现，`current=true`，其余变 false |
| N2 | 建教学班「软工 1 班」→ 加 `stu01`～`stu05` → 授权 `teacher01`（LEAD，发布+评分） | 列表：教师=张老师，学生数=5 |
| N3 | `teacher01` 新建课程 → 发布 → 绑定「软工 1 班」 | 课程卡片「已发布 · 1 个班 · 5 名学生」 |
| N4 | `stu01` 登录「在修课程」→ 打开详情 | 看到课程、教师、目录；资料/作业页签显示归属说明 |
| N5 | `teacher01` 解绑 | 学生端课程消失；教师端详情班级列表为空 |

### 5.2 空数据

| # | 步骤 | 期望 |
|---|---|---|
| E1 | 新教师（无课程、无授权）登录「我的课程」 | 空状态 + 「新建第一门课程」，不报错 |
| E2 | `stu07`（未入任何班）登录「在修课程」 | 「暂时没有在修课程」+ 引导文案 |
| E3 | 管理员查无学期的环境建班 | 学期下拉为空，提交被拦，提示"所属学期不能为空" |

### 5.3 无权限

| # | 步骤 | 期望 |
|---|---|---|
| P1 | 教师直接输 URL `/education/admin/term` | 前端路由拦截或接口 403 显示「无权限」，**不显示表格骨架** |
| P2 | `teacher02` 打开 `teacher01` 的班成员接口 | 403「你不是该教学班的任课教师」 |
| P3 | `stu01` 直连课程详情 `?courseId=<外班课>` | 403「你没有这门课程的访问权限」，不泄露课程名 |
| P4 | 退班后的 `stu01` 刷新旧课程详情 | 403；页面回退到「在修课程」并清空缓存 |
| P5 | 停用账号持旧令牌请求 | 401 → 回登录页（依赖 R-1.5） |

### 5.4 失败

| # | 步骤 | 期望 |
|---|---|---|
| F1 | 同学期重复班级编码 | 500「同一学期内班级编码不能重复」，表单不关闭 |
| F2 | 学期结束日期早于开始 | 前端先拦；绕过前端时服务端 500 |
| F3 | 重复绑定同一班 | 500「该课程已绑定这个教学班」 |
| F4 | 把课程绑到别的老师的班 | 403「只能把课程绑定到自己任教的教学班」 |
| F5 | 断网提交表单 | 「无法连接服务器」提示，不误报成功 |
| F6 | 会话过期时提交 | 401 → 重新登录，回来不重复提交 |

## 8. 提交与评审（按方案第 7 节）

```powershell
git clone <repo>; cd <repo>
git checkout main; git pull
git checkout -b feature/2-0x-简短说明
# 改动后
git add .; git commit -m "feat(education): 2-03 班级管理页接入成员与教师授权"
git push -u origin feature/2-0x-简短说明
# GitHub 上开 PR → 等审查 → Merge
```

- 不要直接推 `main`。
- 作者不能自审。第 1 组审越权，第 3 组审资源版本，第 5 组审答案与成绩公布（本组 PR 主要触发第 1 组）。
- PR 描述必须写：关联 Issue、验证方式、未验证项、是否改契约。
