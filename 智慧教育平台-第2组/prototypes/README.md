# UI 原型工作区

统一存放经核对有效的教师、学生、管理员原型及其本地依赖资源。

## 已登记原型

### admin-login-v1 管理员登录页

- **入口**：[admin-login-v1/login.html](admin-login-v1/login.html)，浏览器直接打开即可查看，单文件自包含，无图片/字体/脚本等外部依赖，不请求任何服务。
- **来源**：2026-10 由用户与 AI 协作在工作区外层生成，2026-10-21 迁入本目录；单文件完整迁移，迁移后核对数量（1 个 HTML）与可打开性。
- **角色/版本**：管理员端，v1；对应需求：管理员登录入口的视觉与交互演示。
- **说明**：演示性质原型，含模拟的安全提示、验证码与角色切换交互，不代表已实现登录、鉴权或任何业务功能；正式登录复用最终若依能力，本原型仅作为视觉参考。与 V2.0 的已知差异：未接入真实身份认证与权限体系，页面文案（学校名称、备案号）为占位。

### console-navigation-v1 三端目录导航原型

- **入口**：教师端 [teacher.html](console-navigation-v1/teacher.html)、学生端 [student.html](console-navigation-v1/student.html)、管理员端 [admin.html](console-navigation-v1/admin.html)；浏览器直接打开即可查看，三文件自包含，共用 admin-login-v1/logo.png 校徽资源。
- **来源**：2026-10-21 由 AI 依据《功能架构优化方案 V3.0》生成——教师端（第二章，两级菜单）、学生端（第三章，两级菜单）、管理员端（第六章，七组菜单），菜单项名称照抄方案原文；教师/学生端「我的课程」下以“课程详情 · 内页签”小标题区分课程列表入口与课程内导航。
- **角色/版本**：教师端、学生端、管理员端，v1；对应需求：三端后台左侧导航目录与页面跳转框架演示。
- **说明**：演示性质原型，仅实现左侧目录、顶部栏与右侧空白内容区；每个菜单项对应独立地址（?g=&i=），点击目录真实跳转到对应分页（URL 变化＋页面重载＋标题与菜单高亮切换），右侧内容区未实现任何业务功能，纯为目录与跳转框架演示。

## 后续补入原型时

1. 先登记原路径、来源作者、日期/版本、对应角色及适用需求，保留原始文件和必要资源。
2. 检查入口、相对链接、图片/字体/脚本和是否依赖外部服务；完整复制后核对数量与哈希，再验证可打开。禁止仅迁入单个 HTML 而遗漏资源。
3. 采用有意义的版本目录，入口可按角色区分，公共资源共用；不引入三套正式应用基础设施。
4. 在本文件登记有效入口、查看方法、原始来源、迁移校验及与 V2.0 的已知差异。发现未知文件先保留并报告。

产品原型可使用模拟数据，但必须标明演示性质；原型中的按钮、静态图表和页面不得宣称为已完成业务功能。本轮不生成新的原型、空页面或占位素材。
